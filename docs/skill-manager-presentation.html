skill-manager
让本机 skill 与 MCP 一眼看清

一个零第三方依赖的命令行工具，用来扫描、推荐、去重、审计、画图谱，并安全治理 Claude Code / Codex / Cursor / Gemini 的 skill 与 MCP。

skill-manager product deck01

why it exists

它不是“又一个 skill”，而是本机 AIDE 工具箱的治理层。

先清点

统一读取各 AIDE 的 skill、MCP、目录来源、分类、上下文估算和静态安全信号。

再判断

回答“该用哪个 skill”“哪些重复”“哪些从没用过”“哪些 MCP 可能拖慢启动”。

最后治理

默认只读；真正会改 AIDE 数据的动作都有确认、备份、dry-run 或安全窗口。

产品定位

  • 面向频繁安装 skill / MCP 的 AI 开发用户。
  • 先把本机真实状态变成结构化目录，再提供搜索、推荐、审计和图谱。
  • 适合本地排查、开源分享、团队入门、长期维护个人 AIDE 环境。

diagnostics05
skm ask

用一句自然语言，找到该用的 skill。

  • 适合“我知道要做什么，但忘了该用哪个 skill”。
  • 默认本地推荐，不调用外部模型，不上传目录信息。
  • 结合名称、description、分类、转换方向、历史使用和可用工具侧。

$ skm ask "把网页转成 Markdown"
任务：把网页转成 Markdown

首选：baoyu-url-to-markdown（两侧，内容抓取与转换）
理由：方向匹配：url → markdown；
意图匹配：网页抓取/转换；
名称高度匹配；描述匹配；任务词相似；
Claude/Codex 两侧可用；历史用过 2 次。

进一步确认：
skm recommend "把网页转成 Markdown" --why

skm risks

把风险按优先级摆出来，但不替你乱动。

  • 风险包括双份未使用、高上下文开销、闲置 MCP、日志体积等。
  • 所有建议都指向可复核命令，不自动删除或禁用。
  • 适合做一般性排查和清理前评估。

risk list09
skm dupes

重复不是一个问题，而是四类问题。

  • 同名多处安装：常见于 Claude 和 Codex 两侧都装一份。
  • 同内容异名：实质上同一个 skill，目录名不同。
  • 同类多实现：功能近似，但不一定应该删除。
  • 文本相似：用于人工判断，不做自动清理依据。

skm graph

把 skill 目录画成知识图谱。

  • 支持 JSON、Mermaid、单文件 HTML 三种导出。
  • 关系包括套件归属、分类归属、重复、流程、反向转换、平台归属、使用 MCP。

shareable overview12
skm list --mcp

MCP 不是越多越好，它会吃上下文。

  • 列出 MCP server 的工具来源、范围、transport 和启动命令摘要。
  • 安全边界：不读取、不输出 env 字段值。
  • 配合 skm audit 判断哪些 MCP 长期没有使用信号。

MCP inventory13
skm sessions

会话日志可以排查，也可以先 dry-run 清理。

  • 按工作区统计会话数、体积、最老和最新时间。
  • sessions --clean 必须先给保留策略，支持 dry-run。
  • 24 小时内活跃会话永不删除；删除前先聚合使用统计。
