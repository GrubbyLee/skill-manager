# Code of Conduct

This project is for people building and managing local AIDE skill workflows. Keep discussions practical, respectful, and focused on improving the tool.

## Expected Behavior

- Be clear and constructive when reporting bugs or proposing changes.
- Share enough technical context for others to reproduce the issue.
- Respect privacy. Do not ask others to reveal API keys, tokens, private paths, or full logs.
- Assume different users have different operating systems, shells, AIDE setups, and risk tolerance.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private credentials, session logs, or personal data.
- Repeatedly derailing issues or discussions away from the project.
- Encouraging unsafe cleanup or destructive operations without clear warnings.

## Enforcement

Maintainers may edit or remove comments, close discussions, or block users when behavior harms the project or other contributors.

For sensitive conduct issues, contact the maintainer through GitHub.
